The idea

Most engines ask you to trust that the simulation is right. This one is built to prove it. Floating-point math drifts between CPUs and compilers — a square root here, a sine there, off in the last bit — and that drift quietly breaks reproducible science and networked multiplayer alike. So every subsystem here avoids the platform math library entirely, computing transcendentals from a strict core in only add, subtract, multiply, divide, and square root. The result is a whole-engine fingerprint: one hash that will be identical on every machine that runs it, or will pinpoint exactly which subsystem disagreed.

Four things it does that most engines don't

Bit-identical determinism

No library trig, exp, log, or pow anywhere in the physics. A strict math core — sine, exp, error function, logarithm, FFT, even the Riemann zeta function — built in pure arithmetic, so the same inputs give the same bits everywhere.

Sabotage-tested gates

Every check has been intentionally broken to confirm it fails when the physics is wrong. A control you have never watched fail is decoration; here all 286 have failed on purpose, once.

Peer attestation

Two machines each emit a signed list of their subsystem hashes; a one-click compare proves byte agreement and, on disagreement, names the exact subsystem that diverged — not "the masters differ somewhere."

Deterministic lockstep

Because the physics is bit-identical, two peers stay in sync on nothing but inputs; a per-frame checksum catches any desync at its frame; and the same headless step replays a match exactly or fast-forwards at 700× realtime.

A concrete example

The strict math core is real enough to walk up the critical line of the Riemann zeta function and locate its first nontrivial zeros — at t ≈ 14.1347, 21.0220, 25.0109 — driving the magnitude to machine zero, bit-identically. To be clear about scope: this locates the zeros and computes the function exactly; it does not and cannot prove the Riemann Hypothesis, which is open. Honesty about what a result is and isn't is the whole discipline.

What's proven, and what's next

Every subsystem is proven bit-identical run-to-run, and the fingerprint computes to the same master across the two runtimes it currently runs in — the terminal and this browser. The attestation protocol is built and gated to confirm that identity across CPU architectures; the one remaining step is running it on physical x86-64 and arm64 hardware and comparing the two files, which the console does with a click on each machine. The engineering is honest about that line: the machinery to earn the cross-architecture claim exists and is tested; earning it is a hardware comparison, not a promise.
