🎤 Dictation — Whisper (speech → text)

Records your microphone in the browser and transcribes it with a locally-run whisper.cpp server (offline, no cloud). Install & start it from ⚙ Auto-Install → Whisper. You can transcribe on this box or hand the audio to a peer that has whisper running (e.g. a faster machine).
