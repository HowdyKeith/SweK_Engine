Assisted: your text is copied to the clipboard and Facebook opens — paste (Ctrl+V) into the composer and click Post. Facebook stopped letting apps prefill status text, so this is the reliable path. A link uses Facebook's share dialog (it prefills the link, not the text). The draft is also saved to the bridge so a screen agent could type it later.

⚙ Page posting (optional, direct via Graph API)

Only needed if you own a Facebook Page and want one-click direct posting. Personal-timeline posting via API isn't available to third-party apps — that's why the default is assisted. Get a Page token from the Graph API Explorer / your app with the pages_manage_posts permission. The token is stored only on this machine.
