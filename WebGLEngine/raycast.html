🚀 Raycast Local LLM

Mac launcher + free on-device AI, wired to the engine's Ollama.
Raycast's local-models feature (v1.99+) runs open-source LLMs through Ollama with no Raycast Pro subscription — only their cloud models are paid. On Intel Macs inference is CPU-only (no Metal), so small models (3B–7B) are the sweet spot: the setup row pulls llama3.2:3b. Apple Silicon can go bigger.

Install

Rows come from the normal install catalog (tool-raycast, tool-ollama, raycast-llm) and run on THIS box. Last step is one manual click in Raycast: Settings → AI → enable → Local Models → sync.

SweK Extension (dev)

    

      
      
    

    
One button = npm install && npm run dev: the bundled extension is copied to a stable
      ~/swek-raycast-extension (so dev never pins an EngineProject folder), a placeholder icon.png is generated,
      and Raycast pops the SweK Engine commands. They stay installed after Stop.

Checked pages become Raycast commands ("Open Pip-Boy", "Open Trading Floor"…) that deep-open the page on the
      bridge URL preference. The three (rich) entries are the full interactive commands from the bundled extension.
      Re-running the maker regenerates ~/swek-raycast-engine from scratch, so the set is always exactly what's checked.

    

  


  

    
Remote — drive a Mac peer (middle man)

    

      
      
    

    

      
      
      
      
      
      
    

    
This bridge relays whitelisted actions to a KNOWN mesh peer's /raycast/peer-exec —
      so from this PC you can execute the whole create-app process on the Mac. Install rows run as background jobs on
      the peer (brew/model pulls take minutes) and are polled here. Pair unknown peers first (LAN discovery, or
      Hosting → external peer for a cloudflared URL).
