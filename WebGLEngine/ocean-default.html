Default ocean — the physics surface, drawn

Six seeded Gerstner waves. The mesh is built from the same function a boat or a submarine would float on, and the buoys sit on it. Drag to orbit, wheel to zoom. It is not the opt-in GPU sea (ocean-spike.html) and not a fitted sea state. Back to the server page.
