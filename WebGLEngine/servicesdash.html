    ▸ full setup guide (what these buttons do, in order)
    

      1. Prereqs. The checklist above probes the box hosting this page for bash, git, and emcc
      (Emscripten). If emcc is missing, install emsdk once:
      git clone https://github.com/emscripten-core/emsdk && cd emsdk && ./emsdk install latest && ./emsdk activate latest && source ./emsdk_env.sh
      — then restart the bridge from that shell so emcc is on its PATH. Windows: run the bridge inside WSL or Git Bash.
      Then hit re-check.

      2. Build. build now runs physics/box3d/build-box3d-wasm-clang.sh on the host: clones
      erincatto/box3d (pinned to the tag field, default v0.1.0), compiles with WASM SIMD, links the SweK shim,
      and writes /vendor/box3d/box3d.js + .wasm. Live log streams below; the dot turns green when the
      artifact exists. Box3D is ALPHA — if a newer tag fails to build, the shim
      (physics/box3d/box3d_shim.c) is the one file to update against the changed API.

      3. Test. run selfTest loads the WASM in THIS browser, steps a scripted 41-body scene 600 ticks, and
      prints a state hash. Do this on two different boxes (each box builds or copies the same artifact):
      equal hashes prove cross-platform determinism → input-only lockstep (a few bytes per tick between peers) is
      safe. Different hashes → do NOT lockstep that pair; sync entity state instead.

      4. Enable. The use Box3D in the engine toggle sets voxelengine.box3dEnabled. Sims check
      box3d.enabled() + (await box3d.init()).ready and prefer a WASM world over the JS
      PhysicsSystem. NOTE: the toggle (and selfTest) are per-browser/per-origin (localStorage) — flip it on each
      box that should use Box3D. Until it's built + enabled, physics runs on the JS system, which already uses Box3D's
      techniques (fixed timestep, 4× sub-stepping, AABB-tree broadphase, lockstep stepN).

      5. Console API (any engine page): window.box3d.init(), .createWorld(),
      .selfTest(), .status(). Rollout for a new tag: build on one box → selfTest against
      the fleet → then enable everywhere.
