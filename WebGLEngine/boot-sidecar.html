Boot sidecar reports

Three rules. Portable by construction — PowerShell is a producer, not the contract, so a report hand-emitted by a shell script reads identically and the Mac half of the fleet is not left unmeasured. Staleness is stated, never silent — an input newer than the report makes it stale, and an input that cannot be checked is assumed stale. A sidecar measures and never grades — verdict-shaped keys are refused at write time and at read time, because a helper that writes {"ok": true} and is believed has moved the grading to the least supervised process in the fleet.
