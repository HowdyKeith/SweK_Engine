🌊 Fluid — verify the GPU on this machine

          

            The engine's fluid solvers are checked against exact analytic answers — Poiseuille's parabola, the speed of sound,
            a shock compressing by exactly six, Rayleigh's 1708. All of that runs on the CPU, and it re-runs on every build.
            The GPU kernel is the one thing that cannot be checked that way, because it was written on a machine with no
            graphics card in it. So it ships with an adjudicator instead — and the adjudicator runs here, on this box.
          

          

            What to do

            1. Open GPU adjudicator below and press run the check. It puts the WebGPU kernel and the verified CPU
               solver on the same problem from the same start, compares them cell by cell, then asks the GPU on its own to
               reproduce Hagen–Poiseuille's paraboloid. Both rows should say AGREES.

            2. Now press sabotage the kernel and run it again. That makes one of the nineteen lattice
               weights 2% wrong — which sounds harmless, and is not: the weights stop summing to one, so the fluid invents mass
               from nothing; the first moment stops vanishing, so it drifts with no force on it; and the speed of sound comes out
               wrong along one axis. Both rows must go RED.

            3. If sabotage does not go red, the check is worthless — and that is far more useful to know than a green tick.
               A check nobody has ever seen fail is a decoration that agrees with you.
