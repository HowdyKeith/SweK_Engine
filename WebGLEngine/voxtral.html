Voxtral, entirely in this tab

Speech recognition with no bridge, no local server and no Windows — and it is 14× slower than real time. Both halves of that are the point. Nothing downloads until you say so.

What it costs, before you decide

Every speed number below is upstream's, on hardware you almost certainly do not have (an NVIDIA DGX Spark). They are recorded with the source attached rather than restated as predictions. The only figure that will ever describe your machine is the one this page measures at the bottom, after you have run something.

1 — What this box can actually do

Read locally. This touches no network and downloads nothing.

2 — Enable the engine

The engine is not shipped with this tree. It is 9.4 MB and the largest thing otherwise vendored here is 3.5 MB, so copying it in would make one opt-in curiosity the biggest file in a repo that publishes public zips. Install it for me does the clone and the staging for you if a bridge is running; otherwise supply the two files by hand, from a staged /vendor/voxtral/ directory or the file picker. Every route ends at the same check: the bytes are matched against a pinned SHA-256 before a single one is executed, whether they came from the installer, the disk or a file you chose. A mismatch is refused outright, not warned about.

3 — Download the weights

Deliberately a second gate. Agreeing to look at a 9 MB engine is not agreeing to spend two and a half gigabytes. Cached in the browser afterwards, so this is once per profile. This step was never exercised where the page was built — huggingface.co was unreachable there (curl returned 000), so unlike the digest check above, nothing proves this path works. Said plainly rather than papered over.

4 — Transcribe, and measure your real-time factor

This is the only speed number on the page that is about your machine. Any audio file; it is resampled to the 16 kHz mono the model expects.

What this page refuses to do
