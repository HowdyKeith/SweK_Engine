# Rig runs, 2026-11-27

Keith's "lets do 1 through 6": these are the runs that need the rig. Each one writes files that are pushed back to the branch
`claude/epic-cori-2hm1my`; a later session reads them. Every command is Windows `cmd` (DOS). Run each block from the folder its
first line goes to.

## 0. A fresh clone of the branch (once per machine)

```
cd /d C:\Users\howdy
git clone --branch claude/epic-cori-2hm1my https://github.com/HowdyKeith/SweK_Engine.git swek-r1127
cd /d C:\Users\howdy\swek-r1127\WebGLEngine
git log -1 --oneline
cd tools\render-qa && npm install --no-audit --no-fund && cd ..\..
node tools/ship/ensureBrowserGatesCmd.mjs
node tools/ship/ensureDxc.mjs --write
```

`ensureDxc` puts `dxcompiler.dll` next to the browser (Windows error 87 on the GTX 1080 box). Run everything as the user that owns the
clone (`howdy`).

## 1. What the new lighting costs on the card (`tools/lightingCost.mjs`)

```
cd /d C:\Users\howdy\swek-r1127\WebGLEngine
node tools/ship/lightingCost-selfcheck.mjs
node tools/lightingCost.mjs
```

- The self-check must end `ALL PASS` (it runs on the software renderer).
- The run takes a few minutes. It loads 18 page variants at 1920 x 1080 on the GPU:
  - the lights demos (WebGL2 and WebGPU);
  - the flight page;
  - the lit sea.
- For each it reads what the card spent per pass (shadows, lit or water, fog) and prints a table.
- It writes `render\lighting-cost-<box>-<time>.json`. If its first line says SOFTWARE RENDERER, it ran on a CPU: stop and say so; the
  file is not written.
- On the GTX 1080 box and the Intel box both, if you can. Send back:

```
cd /d C:\Users\howdy\swek-r1127
git add WebGLEngine\render\lighting-cost-*.json
git commit -m "Lighting cost on the rig"
git push origin claude/epic-cori-2hm1my
```


## 5. Optional: Apple's own check of a USDZ, and a look on the iPhone

The sandbox could not run Pixar's checker, so whether AR Quick Look accepts the files is not yet known. If Python is on the rig:

```
cd /d C:\Users\howdy\swek-r1127\WebGLEngine
node tools/export/usdz.mjs --demo swek-demo.usdz
python -m pip install usd-core
python -c "from pxr import UsdUtils; c = UsdUtils.ComplianceChecker(arkit=True); c.CheckCompliance('swek-demo.usdz'); print('errors', c.GetErrors()); print('failed', c.GetFailedChecks()); print('warnings', c.GetWarnings())"
```

- `errors` and `failed` should both print `[]`.
- Then AirDrop or mail `swek-demo.usdz` to an iPhone and tap it: a small voxel floor with a stone pillar should open in AR Quick Look.
- Any `.glb` converts the same way: `node tools/export/usdz.mjs model.glb model.usdz`.
- In the engine itself, `swekExport.usdz()` in the console exports the loaded world.
- Copy what the checker printed into a message; nothing to push.
