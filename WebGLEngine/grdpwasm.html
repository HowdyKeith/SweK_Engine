RDP in the browser — opt-in

A front door to somebody else's project. Nothing of theirs is in this engine.

Whose work this is

This engine did not write an RDP client. This page installs and runs one that nakagami wrote, on your machine, as its own process.

⚠ Why this one is started on loopback

Read out of their proxy/main.go, which is 110 lines and does three things that are each perfectly reasonable on their own:

  • listen defaults to :8080 — all interfaces, not loopback.
  • CheckOrigin returns true — any web page may open the WebSocket.
  • the destination comes from the query string and is dialled unvalidated.

Together, on a machine that sits on a network, that is an unauthenticated open TCP relay: anything that can reach the port can have it dial any host and port this machine can see — including things behind its own firewall. For make serve on your own desktop for five minutes, upstream's defaults are the right amount of ceremony. For a button that starts it unattended, they are not. So it is launched with their own -listen flag pointed at 127.0.0.1. Their source is not modified, patched or forked — this page simply declines to pass the argument that publishes it to the network.

1 · Install

Clones the pinned commit into … (outside this tree) and runs their make all. Their go.mod asks for Go 1.26.3, so the Go toolchain may download itself; the build produces about 20 MB of artefacts and takes a few minutes cold.
