optional: keep this peer running across reboots (persistence)

A button on a web page cannot install anything into Termux — the browser has no filesystem or shell access. What it can do is hand you the exact commands. Install the Termux:Boot add-on from F-Droid (the Play Store build is deprecated and will not run boot scripts), then paste these into Termux once:

download termux_boot_peer.sh

This gives start-on-boot and Doze survival, not a foreground service — Android still reaps Termux under memory pressure, and a reap in the ledger confirms that prediction rather than failing it. The phone writes swek-persistence-ledger.jsonl to Downloads; upload it with the transcript and the desktop grades survival. Nothing here is submitted to F-Droid or the Termux repo — those host the app and its add-ons; our scripts run inside Termux and only depend on Termux:Boot.
