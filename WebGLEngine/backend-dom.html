Third backend — DOM/CSS against WebGL2

Both renderers draw the same quads, at the same counts, on this machine, in the same frame budget. The point is not which is faster in general — WebGL2 will win — it is where the DOM renderer stops being usable, and whether that ceiling is above or below what the no-GPU fallback would actually need.

Both paths animate every quad every frame, so neither can win by being static. The canvas and the DOM layer occupy the same box.

Press run. Takes about twenty seconds — it sweeps quad counts and measures each for a fixed number of frames.
