🤖 Join as a SweK Android Peer

someone running a SweK Engine invited this phone to volunteer as a compute peer. Here is exactly what that means before you decide.

what this will and won't do

✓ download a set of readable script files into ~/swek-peer on this phone
✓ when you choose to run them, execute a physics test suite and report the results
· it will not install an app, ask for root, start on boot, or touch anything outside that one folder
· nothing leaves this phone unless you hand the results file back yourself

step 1 — get Termux (one time)

Termux is a terminal app. Install it from F-Droid (the Play Store build is deprecated). Then in Termux:
pkg install nodejs
termux-setup-storage

step 2 — fetch the peer (nothing runs yet)

This downloads the files and stops. Read them if you like — that is why they are scripts, not a binary.
curl -fsSL "LOADING..." | bash
copied

step 3 — run it when you're ready

cd ~/swek-peer && bash tools/roundhouse/termux_peer.sh
The suite takes about 15–25 minutes. It writes android-phone.json into your shared Downloads. To contribute the result, hand that file back to the operator (they will tell you how — usually it is picked up automatically from Downloads).

the GPU part (optional)

In Chrome on this phone, open the engine's /magmap-android.html, tap run, and download the report. It tests whether this phone's GPU agrees with the reference to the last few digits. Also optional, also yours to hand back or not.
