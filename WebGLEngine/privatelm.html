📱 PrivateLM

language models that run on your phone, and a cloud fallback — a separate project (orailnoor/cross-platform-llm-client, MIT), linked here for convenience. It does not touch any SweK protocol; the engine reaches it through the OpenAI-style API the app can serve.

Releases (latest)
iPhone / iPad
Sideloaded with AltStore. The project's README says a release carries an iOS package (PrivateLM-iOS.zip); the four newest releases on GitHub when this page was written had none, so look through the releases for one before you start. Run AltServer on a Mac or PC, install AltStore on the device, download the package from the release in Safari, unzip it, open the .ipa with AltStore, and turn on Developer Mode (iOS 16 and later). Sideloaded apps expire after 7 days and AltStore renews them while it can reach AltServer. An iPad is the better target: the models need the memory.

Use it from the engine

In PrivateLM open the server screen, load a model, set an API key and turn on network access. The key matters twice: the app listens on the network only with one, and it sends the headers a browser needs only when one is set. Then type the phone's address here (the app shows it).
