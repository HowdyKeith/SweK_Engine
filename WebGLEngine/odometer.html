Where this may be used was decided before this page existed. ui/morphDigits.js settled it at v3531: a number may morph only if a reader would never need to trust it mid-transition. That admits numbers changing slowly and discretely — a gate count ticking once a round, a version marker — and excludes every live gauge. An odometer is subject to it twice over, because a roll takes about three and a half seconds and the dock gauges poll every frame: it would never finish before the next value arrived.

It is not a duplicate of that morph. There the glyph strokes bend, so intermediate frames show shapes that are not valid digits. Here a strip of real digits scrolls. Different things to say, so neither is the default for the other's elements — the selectors are disjoint and the gate proves it.
