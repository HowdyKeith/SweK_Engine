## How to join the board (the interface is the one in `brain/switchboard.mjs` at `f4b55956`, copied into the gates; none of the modules imports the board)

```js
import { leakyArm } from "./pilotLeakyHeading.mjs";
import { plainNetArm } from "../render/subAquariumPlainNet.mjs";
import { fishArm } from "../render/subAquariumFish.mjs";
import { plain14Arm } from "../render/subAquariumPlain14.mjs";
board.addArm(leakyArm());                                                              // controls: ["autopilot"]
board.addArm(leakyArm({ id: "leaky-unit-off", weights: [0.9999, 0], controls: [] })); // the no-memory lesion = the dropout autopilot, exactly
board.addArm(plainNetArm({ record }));                                                 // record = a line of brain/rig-results/plainNetStudy.jsonl
board.addArm(fishArm({ file: fishJson }));                                             // brain/pilotSubWeightsFishWip.json, parsed
board.addArm(plain14Arm({ file: plain14Json }));                                       // brain/pilotSubPlain14Wip.json, parsed
// the arms the board should hold the 963-weight fly networks against, so that "ties its control" can be said:
//   stateful fly:  controls: ["autopilot", "leaky-unit", "plainnet-P/B/mn:3", "plain14-954"]
```
All arms are `layer: "flying"` with `entry()` and `register(tank)`; `register` calls `tank.registerPilotKind(circuit, kind)`, which the board's dropout task calls on each fresh tank before `sync`.

**What that says, at the size it has.**
* **The settled-error score cannot tell a heading memory from none** (the navigator, whose heading estimate is off by a thousandth of a radian, TIES the autopilot on it): the sub turns at 0.06 rad/s, a half turn takes 40 s, and a tick counts as settled 12 s after a retarget, so the error is mostly how fast the pilot turns. **The dark cost can**: the navigator and the leaky unit pay (almost) nothing when the compass goes out, the autopilot pays 0.029 rad, and every trained residual net pays more than the autopilot (+0.012 for the fish, +0.022 for the plain14 net, +0.065 for the hazard net).
* **The residual nets win the settled error by turning faster and lose more in the dark**: a plain 14-50-4 net with no wiring lowers the settled error three times as much as the wired fish. That is the notes' "the gain of every residual pilot is generic", seen in the tank. A round that means to test MEMORY should read the dark cost (or a heading-estimate error), not the settled error; that registration is the other chat's to write.
* The paired memory test's replication (`brain/TANK_PILOTS_WIP.md`) says the stateful fly pilot beats the same weights with the memory wiped in the lit windows too (pooled P1), so for that policy the memory is not compass-specific; the dark cost is the measurement made for that question.
