🗣️ Alexa command
Type a command and the engine sends it to an Echo through Home Assistant, as if you'd spoken it. Needs one of: Alexa Media Player (HACS — gives each Echo as a media_player) or Alexa Devices (official integration — uses a device id).
Reverse: "Alexa, make the ball red" → control the engine
Alexa routines can only act on Alexa-known devices, so expose a little HA script to Alexa (via HA Cloud / the Alexa skill), then have it call the bridge. Three pieces:

1. configuration.yaml — a rest_command to the bridge:

rest_command:
  swek_exec:
    url: "http://PC_IP:8787/push2run/exec?cmd=exec&line={{ line | urlencode }}"
    method: GET

2. A script (expose this one to Alexa) that runs the engine line:

script:
  make_the_ball_red:
    sequence:
      - service: rest_command.swek_exec
        data:
          line: "window.swek&&swek.setBallColor('red')"

3. In the Alexa app: Routines → When you say "make the ball red" → Action → Smart Home → run that script.

Swap the line: for whatever JS your demo uses. No engine code needed — it rides the existing /push2run/exec.
Settings → Devices & Services → your Echo → the device-page URL ends in its id.
