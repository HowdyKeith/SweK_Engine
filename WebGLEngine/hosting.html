☁️ Cloudflare Tunnel checking…

Public HTTPS URL, no client for visitors to install. Best when other people (your PetFBI admins, viewers) need in from any browser. Free, includes DDoS/WAF.
  1. Quick tunnel (the button above): runs cloudflared tunnel --url http://localhost:8787 and shows a random trycloudflare.com URL. Great for a smoke test; the URL changes each run.
  2. Permanent URL (your own domain): at one.dash.cloudflare.com → Networks → Tunnels → Create → Cloudflared, then map a hostname to http://localhost:8787. Runs as a service, survives reboot.

🌐 Permanent URL (named tunnel)

A permanent https://swek.yourdomain.com needs a domain on your Cloudflare account (free plan is fine). This generates a one-run setup script for this machine's OS — it installs cloudflared, creates the tunnel, routes DNS, and installs it as an auto-start service. One step (cloudflared tunnel login) opens a browser for you to pick your domain.
Free alternative — Drive URL pointer. No domain needed. This box writes its current tunnel URL to a fixed file in your Drive SweK folder; peers read that file to always find the live URL (the file is permanent even though the URL changes). Requires Drive to be configured.

🔗 Tailscale checking…

Best when it's just you + a few trusted devices. Serve = private to your tailnet (nothing public). Funnel = public HTTPS, visitors don't need Tailscale.
Both give the same permanent <machine>.<tailnet>.ts.net URL and persist across reboots. Serve = only devices on your tailnet can reach it. Funnel = anyone on the internet (needs HTTPS enabled in your tailnet; the button surfaces the enable link if not).
  1. First time only: install above, then run tailscale up in a terminal to sign in. Refresh this page — the controls appear once you're connected.
  2. Then just click Serve or Funnel here — no terminal needed. (macOS: use the open-source/standalone Tailscale variant for Funnel.)

🕺 NetBird checking…

A fully open-source, self-hostable WireGuard P2P mesh (an alternative/complement to Tailscale). Devices form direct encrypted peer-to-peer tunnels; only key/discovery is brokered. If a box is on a NetBird mesh, SweK can use its 100.x mesh IP as a peer.
not detected on this box
Client agent: Windows winget install NetBird.NetBird, macOS brew install netbird, Linux the netbird package — then this box can join a mesh. To host your OWN control plane, use the NetBird entry in Settings → Services (needs a public domain + ports 80/443/UDP-3478). Or use NetBird's free managed cloud — the client is the same either way.
