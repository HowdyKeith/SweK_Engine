ASCII Video Player

Plays a JSON frame document: { fps, cols, rows, frames: ["…","…"] }, each frame being rows lines of exactly cols characters. This page owns no generator. It imports text somebody else produced — a gradient-descent converter, a lookup-table one, or a hand-typed grid — and never asks which. Validation refuses the failures that would otherwise render fine and look like art: a short row, a missing line, a stray tab.
