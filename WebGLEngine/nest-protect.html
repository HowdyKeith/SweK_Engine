🔥 Nest Protect · via Home Assistant
Heads-up on Nest Protect + HA: the official Home Assistant Nest integration uses Google's Device Access (SDM) API, which does not expose Nest Protect — only thermostats, cameras, doorbells and displays. So Protect smoke/CO status only shows here if some other integration is already feeding smoke/CO entities into HA. This panel reads whatever smoke / carbon-monoxide / battery entities your HA exposes and groups them per detector.
