Whose work this is

No LICENSE file exists in this repo at any commit checked, which means all rights are reserved by default. This page never vendors it, never edits it, and runs it exactly as published rather than re-deriving its commands.

4 — Or: a double-clickable Terminal launcher (recommended)

    
This writes a .command file — a script Finder runs in Terminal when you
      double-click it. It is the better option, not just another one: the mount button above uses
      sudo -n, which refuses to prompt, so it only works if you already ran sudo -v in
      a Terminal. A .command runs in Terminal.app, so Terminal asks for your password
      — it still never reaches this server, but there is nothing to do first. The script also asks
      Continue? [y/N] before touching any disk, and lets you pick the volume from the mounter's own
      menu rather than trusting a selection this page cached.
