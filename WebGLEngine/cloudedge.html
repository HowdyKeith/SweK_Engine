📷 CloudEdge Camera · local RTSP → go2rtc
First, in the CloudEdge app: open the camera's settings and turn on ONVIF (a.k.a. "Local RTSP" / "LAN protocol") — it's off by default — and set a password. The username is always admin (RTSP on port 8554, ONVIF on 8000). Then fill this in to register the local stream with go2rtc so it shows in the camera picker.

Best of all: if your camera does ONVIF, the go2rtc panel's scan can often auto-detect the exact path — no guessing. The database is iSpyConnect (the largest crowd-sourced RTSP list, per-brand); the search button pre-fills the brand + model so an AI answer or forum post fills in the path.
If it won't connect: some CloudEdge cams only do Cloud RTSP (a dynamic, expiring link via Tuya's cloud) and can't be streamed locally — if there's no ONVIF/Local-RTSP toggle in the app, that's likely yours. Also try the other path style if one fails, and test the URL in VLC (Media → Open Network Stream) to confirm the camera side before blaming go2rtc. go2rtc must be installed & running (go2rtc panel), and may need a restart to pick up the new stream.
Motion + spotlight: ONVIF gives video only. For motion events and turning the camera's light on, add the cam to Home Assistant via Tuya or LocalTuya — its motion shows up as a sensor (which the Presence panel's room rules already react to) and its spotlight as a switch you can flip from the Lights & switches panel or a rule.
