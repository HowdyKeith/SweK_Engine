📺 Show a page on the Echo Show
Alexa has no built-in command to open a URL — "Alexa, open Silk" only opens the browser to its homepage. To open a specific page you install a tiny one-time skill that uses the APL OpenURL command, then this panel fires the text command that triggers it.
  1. Install aldadic's "home-assistant-on-echo-show" skill (or the community "MyPage" skill). Name it dashboard viewer (or set the name below).
  2. In the skill, map page numbers → this PC's LAN URLs, e.g. page 1 → http://<this-PC>:8787/wall.html, page 2 → /board.html.
  3. Needs the HA Alexa Devices integration (for send_text_command) + your Echo's device id below.
Heads-up: the Echo Show drops the browser back to its home screen after a few minutes of inactivity and forgets the page — it's not a true always-on kiosk. For an always-on panel, use a Fire tablet + Fully Kiosk or one of the wall phones.
