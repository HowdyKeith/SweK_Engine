Galaxy Profile SVGs

An install button for somebody else's tool, run on your own machine, with nothing of theirs copied into this tree. It renders four animated GitHub-profile SVGs (a spiral galaxy header, a stats card, a language radar, a project constellation) from real GitHub stats.
