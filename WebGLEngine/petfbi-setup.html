Setup & Workbook

Workbook

All routing lives in one .xlsx: a <STATE> Pages sheet per state, an Admins sheet, and a Templates sheet. Set where it lives, then create it.

Add a Facebook page

Each page you post to needs its state, page name, and (ideally) its numeric page ID. Facebook doesn't expose the ID without logging in — find it on the page: About → Page transparency → Page ID, or via lookup-id.com / findmyfbid.com. You can add the page without the ID and fill it in later.

Admins

People who get emailed the assembled report for their towns. Towns is a comma-separated list (blank = all in the state).

Template editor

Post body per status × type. Placeholders in [BRACKETS] are filled from the parsed report; unfilled ones are dropped. The preview on the right mirrors the engine using sample values.
