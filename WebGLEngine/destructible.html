Destructible — an exact hole in a wall

A jagged blast shape subtracted from a solid slab by BSP mesh booleans (physics/mesh/meshCSG.mjs, method from evanw/csg.js, MIT). The rim lies on the wall's own plane at any angle, with no grid — which is the one thing neither the voxel path nor the SDF path next door can do. Only the polygons a blast can reach are cut, through the trianglesInBox query added to mesh/meshBVH.mjs.

Drag to rotate. Every line is a polygon edge, so the mesh you see is the mesh that exists — watch the wall shatter into coplanar fragments that settle takes back.

What this does not do

It makes the hole, not the rubble. A BSP subtraction returns one connected mesh with a hole in it; pieces need connected components and an inertia tensor, which is physics/voxel/fracture.js and is already exact. Nothing here is duplicated from it.
