🧩 WASM demo — portable SHA-256 checking module…

One sha256.wasm (2.5 KB) runs byte-identically on every box — Windows, the Intel Mac, the peers — executed by the bridge's own Node WebAssembly. No Docker, no per-OS binary. This is the class of compute WASM genuinely replaces: stateless, portable, sandboxed.

The endpoint runs the same input through the WASM module and Node's built-in crypto, then compares them — proving the portable .wasm matches the reference implementation exactly (and the existing VBA / JS / Python SHA-256 demos). Standalone runtimes (Wasmtime / Fermyon Spin) are in the GitHub & Services catalog if you want to run .wasm outside Node too.
