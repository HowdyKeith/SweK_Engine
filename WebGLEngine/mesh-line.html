═ Wide lines · what gl.lineWidth cannot do

top: gl.LINES with gl.lineWidth(width) — ?
bottom: the same path as a triangle strip, offset in the vertex shader
gl.lineWidth is not deprecated and it is not an error — the Core Profile permits an implementation to support only a width of 1, and every desktop driver takes that option. So the call succeeds, reports nothing, and does nothing. The line below it is the same points expanded into a triangle strip, with the sideways offset applied after projection so the width is measured in pixels: it stays the same thickness as the path recedes, which a world-space ribbon cannot do. The joints are mitered, and a miter is capped — at a full reversal the miter length is 1/cos(θ/2), which goes to infinity.
