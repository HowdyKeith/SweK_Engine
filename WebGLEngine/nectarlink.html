🔗 Nectarlink

your Android phone and Windows PC working as one — local-first, end-to-end encrypted, no account. A separate project (thtbee/nectarlink), linked here for convenience.

install (v0.1.4)

💻 Windows 10/11 x64 installer 📱 Android 8+ APK
The Windows installer is not code-signed yet, so SmartScreen may warn on first run. Play Protect may block the APK in some countries — see the project README for workarounds. Linux (x86_64) and Windows ARM64 are planned for the next release; macOS is a limited preview.
Latest builds and notes: github.com/thtbee/nectarlink/releases — these links pin v0.1.4, the version this page was written against.

what it does

Phone notifications, SMS and calls on the PC · clipboard and file transfer · screen mirroring and phone apps in windows · phone as touchpad, keyboard, remote or webcam.

what it is to SweK today

· Not connected to the GPU Brain Peer. Nectarlink moves notifications, files and input between a phone and a PC; it does not schedule compute or carry SweK traffic.
· Nothing in the engine calls it. The install panel above only fetches and starts the vendor’s own installer, so you can run it alongside SweK.
✓ Possibly useful later: it publishes a protocol spec (length-prefixed CBOR over QUIC, with a capability registry) and Rust crates under GPL/MPL. A peer link could borrow the idea, but that is not evaluated or built here.
The Android Invite page is the SweK way to put a phone to work as a compute peer.
