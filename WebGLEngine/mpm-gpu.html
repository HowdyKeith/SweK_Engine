◆ Drift — the material point method on the GPU

The same loop mpm.html runs, and the same modules the gates grade. Every stage of the kernel is one of them: the APIC transfer, the grid solve, neo-Hookean stress, the force scatter and the return mapping. The kernel holds no material constant at all — stiffness, friction coefficient and plastic clamp limits are all computed in JavaScript by physics/mpm and passed in as uniforms, so there is nothing retyped that could quietly disagree. The CPU page runs 25 particles. This one runs tens of thousands, and the arithmetic is underneath.
