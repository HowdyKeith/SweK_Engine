🚀 Endless Sky — flown by SweK's clean-room EV engine

What this is

Endless Sky's data, loaded through the same engine that flies Escape Velocity. The adapter parses ES's text data and emits the identical uni graph that evData.js produces, so galaxyMap.js, systemView.js, flightView.js and combat.js fly it with no engine changes.

Endless Sky is GPLv3 and its data and art are freely redistributable. These modules ship no game content — they transform files you supply. Ship art loads from the ES repo's raw images by default; set window.ES_IMAGES_BASE to run fully offline.

Fly it in Stellar Atlas ↗ README-endless-sky.md es-universe.json —

Drop es-universe.json on ev.html for an instant galaxy, or drop the raw ES data/ .txt files and let the adapter parse them live. Either works — and either works from inside a .zip.

Build the universe (node baker)

Runs node es-build.mjs <data dir> es-universe.json on the SweK server. Point it at a clone of endless-sky/data. The bake writes to a temp file and only swaps in on success, so a failed build never destroys a working galaxy.

Streams the ES source tarball from GitHub and extracts only data/**.txt (~10 MB of text out of a ~350 MB download — GitHub offers no smaller listing-free archive). No token needed. Coverage — what the adapter ignores

  

    The adapter consumes a fixed set of ES root node types and drops the rest silently. This is the measured
    inventory, baked into the universe by ev/esCoverage.js. An ignored type is only a problem if you
    wanted it — but you should get to know.
