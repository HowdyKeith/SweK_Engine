Three repairs, and one of them lies

Two rounds established that a handful of cells have gradients that cannot be determined from cell averages at all — exactly two in 2D, 6n in 3D. Three repairs were named and none tested. All three are measured here against the same exact key: reproduce a linear field exactly, or do not.
The unrepaired cell reads 1.000, which is a refusal. A zero-Neumann repair reads 0.547, which is an answer. The error got smaller and the situation got worse — 1.000 is g = 0, a flag a caller can test for; 0.547 is a plausible vector a solver would use without hesitating.

1. The three repairs

The vertex stencil is exact and asserts nothing about the physics — pure geometry, the only one a solver can apply without knowing what the boundary is. Dirichlet is exact and costs no stencil, from data a solver genuinely has. Zero-Neumann restores the rank and gets the answer wrong, because the field's normal derivative there is not zero. Rank is not correctness.

2. Is Neumann broken, or is the assertion false?

Supplied with the honest normal derivative, the same machinery is exact — same rank, same stencil, same rows, only the right-hand side differs, and the error moves by thirteen orders. The mechanism is sound; the assertion was what was false. "Neumann repairs the rank" is true. "A zero-Neumann boundary is a safe default" is a claim about the field.

3. Where a rule is applied is as load-bearing as the rule

A repair is usually written as a boundary rule and applied to every boundary cell. But 92 of the 94 boundary cells were already exact, so a false rule applied to all of them can only do harm — it takes them from 1.3e-14 to 5.4e-1. A true condition applied everywhere is harmless, because an extra row consistent with the field cannot move a fit that already passes through it. So "apply it everywhere" is safe exactly when the condition is true — which is not a numerical safeguard.
