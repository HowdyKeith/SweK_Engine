Why this page exists

A prediction made after the measurement is not a prediction. These were all written into the changelog on the day the code shipped, before anyone ran it — and each one names the result that would prove it wrong, because a claim that cannot be wrong is not a claim, it is a mood.

They are open because they need a GPU, a second machine, or Windows — and the box that wrote them has one CPU, no GPU, and no emsdk. Being unable to run something is not a reason to soften what you said about it.
