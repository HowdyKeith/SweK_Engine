Run it — three commands, on a Mac

THIS PAGE CANNOT RUN LAPACK FOR YOU AND WILL NOT PRETEND TO. Nothing in the browser can compile a C file or link Accelerate, and a button here that appeared to do it would be the worst object in this subject: it would look like corroboration and be a page talking to itself. Copy these into a terminal in the WebGLEngine directory. The last one re-runs the grade above. 
node tools/roundhouse/externalLinalg.mjs --write-problems
clang -O2 tools/roundhouse/external-linalg.c -framework Accelerate -o /tmp/exlinalg
/tmp/exlinalg tools/roundhouse/external-linalg-problems.txt > tools/roundhouse/external-linalg-answers.json
node tools/roundhouse/externalLinalg.mjs

What agreement here would mean, and what it would not

THE RANK ROWS ARE WORTH MORE THAN THE DETERMINANT ROWS AND THE TABLE SAYS SO. rank decides controllability and observability, and this engine decides it by elimination against a typed tolerance of 1e-9 while LAPACK decides it from the singular value spectrum. Those are unrelated derivations of one integer. Two float answers agreeing to 1e-12 can always be an accident of tolerance; an integer agreeing across two unrelated methods cannot.

The float tolerance shown per row is derived from machine epsilon and the problem's size, not typed. A Hilbert 4×4 is in the set on purpose: it is where “they agree to 1e-12” becomes a claim about the problem rather than about either solver.

NOT A BENCHMARK. The BLAS underneath will reach the AMX/SME matrix units on Apple Silicon and that is not the reason to do this — these matrices are 2×2 to 4×4 and the timing is meaningless. The reason is independence.
