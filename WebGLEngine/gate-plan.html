The gate planner

A 3-minute subset that reliably contains the gates a change can reach is worth more than a 26-minute one that gets skipped. Ordering is a dependency fact, not a filename guess: gates whose direct imports include a changed file go first, then everything the change reaches transitively, then the rest — cheapest first inside each band, so a run cut short still covers as much as it could. Costs come from gate-timings.json, observed on real suite runs. Gate: tools/ship/gateSelection-selfcheck.mjs.
Regenerate this snapshot: node tools/ship/planSnapshot.mjs <changed files…>
Run a plan for real: node tools/ship/selfchecks.mjs --budget 60 --affected <changed files…>
Unrun gates are not a claim that they pass. And a plan is not a ship: verify.mjs is not decomposable this way and still catches what these cannot.
