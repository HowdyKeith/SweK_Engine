The control this arc owed

Three rounds measured a zero-Neumann repair producing a wrong answer — 0.547 in 2D, 1.134 in 3D, worse there than doing nothing — and each said the same thing: the mechanism is sound and the assertion is what is false. Without a field where the assertion is true, that was a claim about one field dressed as a claim about a method. Named three times, deferred three times. Here it is.
The field is u = a + c·y — linear, so the exact key still applies and the true gradient is the constant (0, c), and varying only in y. The left and right walls have outward normal ±x, so grad·n = 0 exactly: genuine zero-flux walls. Top and bottom have normal ±y and grad·n = ±c, which is not zero. The same rule is true on one wall and false on another, in the same run, on the same field — and the two rank-deficient corner cells touch one face of each kind.

On the wall where the assertion is true, zero-Neumann is exact — rank restored, no boundary data needed, no stencil widened, and it leaves the healthy cells alone. Where the wall really is a zero-flux wall it is the best of the three repairs by every measure. Two rounds of calling it the dangerous one were describing a field, not a method.
On the wall where it is false it is worse than the refusal, and it damages the 92 healthy boundary cells. Applied to both faces of the same cell it lands in between and is still wrong — the true row and the false row are averaged by the fit, so a correct condition does not rescue an incorrect one sitting beside it. Same code, same mesh, same field; only which faces get the row differs, and the answer moves thirteen orders. Rank is restored in every case, including the wrong ones.
So the recommendation stands and gains a clause: Dirichlet where the data exists; the vertex stencil only where the rank is deficient; zero-Neumann where the wall is actually a zero-flux wall — which is a fact about the problem, not about the mesh — and never as a default, because the same rule on the next wall along is worse than doing nothing.
