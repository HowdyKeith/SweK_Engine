Why the config column exists. Only 24% of the numeric claims in the lab's own gates can be reproduced by re-running the device they name — the rest were measured at a particular setting that never got written down. A number without its configuration is not a result, it is an anecdote.

What you can do with the CSV. It is long-form — one row per observable — so a spreadsheet, pandas or R reads it with no adapter. Paste a config cell back into the box above and you get the same numbers, on any machine.
