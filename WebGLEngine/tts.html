🔊 Local TTS

…

Local text-to-speech on the bridge PC. SAPI (Windows, zero install) can speak aloud or render a WAV. say (macOS, zero install) uses the Mac's built-in voices — speaks aloud or renders a WAV. Piper (neural, better quality) renders a WAV the browser plays — needs the piper binary + a voice .onnx model.

→ To make the in-engine avatar speak with this voice, run kpop.useLocalTts(true) in the engine console (sticky; falls back to browser TTS if the bridge is down).
