EV Loader — bring your own data, then fly in Stellar Atlas

Stellar Atlas is an independent, clean-room engine that reads Escape Velocity–format data files. It can't ship the game's worlds or art — you point it at a copy you're entitled to, and it flies your galaxy locally in the browser.

Clean-room, your files only. This engine contains no EV content. Its parser is built from the published byte-layout spec (the EV Nova Bible), not from any game files. Everything you load is parsed on your machine — nothing is uploaded.
1

Get an EV data set

Ambrosia Software closed in 2019 and the registration server is gone, so the community keeps the games running. escape-velocity.games is the modern home: EV Nova Community Edition (Windows) and WineNova (Mac), plus EV Classic and EV Override as free Total Conversions.

2

Find the data file

Inside an EV Nova install the universe lives in the Nova Files folder — nova.ndat (or .rez) plus any plug-in files. Classic Mac copies use the game's resource fork; .bin (MacBinary) and AppleDouble work too. Any one of those is what you load next.

3

Load it into Stellar Atlas

Launch the engine below, then drag your data file onto the window (or click to pick it). It parses locally and drops you on the galaxy map — click a system to fly in. Bring a friend on the same data file and you'll see each other as ghost ships.

Just want to fly something free?

Endless Sky is a fully free, open-source game in the same spirit (GPL v3, hundreds of contributors). It uses its own data format, so it won't load in Stellar Atlas — but it's a great standalone if you don't want to chase EV files.
