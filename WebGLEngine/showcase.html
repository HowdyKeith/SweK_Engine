SweK — a personal distributed OS

Every machine I own runs the same software, so where a program runs, which screen shows it, and which device drives it are runtime parameters — not things I deploy for. The 3D engine you'll see isn't the product; it's the window manager. The product is the fabric underneath it.
Closest ancestor: Plan 9 — compute anywhere, display anywhere, resources addressed uniformly across machines. Built solo over ~1,900 iterations. Everything below runs with no cloud, no deploy step, no accounts.

The Fabric

One trivial computation, run five ways — here, on another machine, shown to a remote screen, driven by another device, and in an isolated runtime. The hash stays identical everywhere (same computation); the "ran on" label changes (it moved). This is the whole thesis in one number.
