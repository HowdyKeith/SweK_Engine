🧠 Brain Quadrants — multi-tasking the solver across GPU memory

Several INDEPENDENT navigation problems (different rooms, different goals) are packed into ONE grid with impassable gutters between them, and solved in a SINGLE pass — then unpacked. This is the same mechanism the engine can use to give many map regions (or many kaiju packs) their own flow field concurrently without N separate GPU dispatches. Each panel below is one quadrant's unpacked flow field. The isolation is exact: packed results are bit-identical to solving each room alone (verified).
