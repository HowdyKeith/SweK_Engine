◆ MPM GPU adjudicator

This kernel was written where there was no GPU to run it on. It has since been run on a WGSL interpreter and agrees with the graded loop to about 1e-7 relative — but an interpreter is not a driver. It does not prove the shader compiles on real hardware, and because it runs invocations one after another it cannot see a race. So the kernel is checked here, on your hardware, against physics/mpm/step.mjs — the loop the gates grade — and then asked to earn the free-fall key by itself.
