gputaskman

a monitor for what is inside your GPU, and a one-button session that starts a model and saves the numbers — a separate project (shanselman/gputaskman, MIT), linked here for convenience. It does not touch any SweK protocol.
Early, experimental software that this engine did not write. The install button below runs uv tool install gputaskman or pipx install gputaskman on this machine, which fetches a package from PyPI; the engine does not pin or scan it. It reads NVIDIA and AMD GPUs (Windows 10/11 and Linux; Apple Silicon from a clone); Intel GPUs are not supported yet. The engine's bridge must be running on this machine.

2. Install gputaskman

uv tool install gputaskman

Press “Check this machine” first: the buttons turn on for the installer that is found.

  
By hand, in any terminal, the same commands work. uv and pipx put the program in ~/.local/bin; if the engine says it still cannot find it after installing, restart the bridge from a NEW terminal so its PATH includes that folder. The project also offers unsigned portable downloads on its releases page.





3. Start a model, take the snapshots



  
Needs Ollama running on this machine (the Windows app starts it; otherwise ollama serve) with the model already pulled (ollama pull <name>). The session takes a baseline snapshot, loads the model, snapshots again, asks for a short answer while snapshotting a third time, and saves everything as one file. A large model can take minutes to load.
