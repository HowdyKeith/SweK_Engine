SweK · box3d + fluid loading…
box3d owns the rigid bodies; the fluid supplies buoyancy + drag. Each frame: box3d transforms → fluid stamps them as moving solids → the fluid pressure over each body is fed back to box3d as a force → box3d resolves gravity, contacts, and the buoyancy. Light bodies (teal) float, heavy ones (amber) sink. The coupler (physics/fluidBox3d.js) is unit-tested against a mock 3D world; it uses the real box3d WASM when built (see the box3d page), otherwise a JS gravity fallback so buoyancy still shows.
