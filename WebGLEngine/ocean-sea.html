Ocean — the opt-in GPU sea

The vendored web-ocean sea behind a tier switch. In auto it is timed on this GPU first and unloaded if it cannot hold 30 frames per second; in on it stays and the reading says how slow it is; in off it is never loaded. The default water that every GPU can draw is ocean-default.html. The sea can be asked to match the physics sea's swell height and length (the matched setting); the table below says what that does and does not line up. Back to the server page.
