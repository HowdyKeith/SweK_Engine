🖥 DuoDesk

Mac, Windows, Linux and Android working as one desk — one mouse and keyboard, shared screens, files, clipboard and notifications, no account and no cloud. A separate project (0xCodez/DuoDesk, GPL-3.0, a fork of TwinDesk), linked here for convenience.

install (v2.5.0)

 macOS (Apple Silicon) 💻 Windows x64 💻 Windows ARM64 🐧 Linux .deb 🐧 Linux AppImage 📱 Android APK 📱 Android full APK
NixOS: nix run github:0xCodez/DuoDesk. All files and newer builds: github.com/0xCodez/DuoDesk/releases — these links pin v2.5.0, the version this page was written against.
The apps are not code-signed. macOS: Privacy & Security → Open Anyway (or xattr -dr com.apple.quarantine /Applications/DuoDesk.app). Windows: SmartScreen → More info → Run anyway; Smart App Control on Windows 11 can block unsigned apps outright. Android: allow unknown apps, then More details → Install anyway if Play Protect objects; the full APK is easiest installed from the computer over wireless debugging.

what it does

One keyboard and mouse across machines · extended or mirrored displays · the other computer’s apps in their own windows · shared clipboard and files · phone calls, texts and camera on the computer · Wi-Fi, USB, Bluetooth or Wi-Fi Direct. Per its README the only internet request is an update check against GitHub releases, which can be turned off.

what it is to SweK today

· Not connected to the GPU Brain Peer or anything else in the engine. It shares input, screens and files between your own devices; it runs no compute.
· It overlaps with Remote Desktop and Nectarlink. This page is a link so you can install it alongside SweK, not a SweK feature.
