📖 Setup guide — Tasker + AutoNotification on phone
  1. Install on your phone (Play Store):
    • Tasker (paid, ~$3) OR Macrodroid (free alternative)
    • AutoNotification (companion app, free with optional in-app purchase)
  2. Grant Notification Access when prompted: Settings → Apps → Special access → Notification access → enable AutoNotification
  3. Create a Tasker Profile:
    • Event → Plugin → AutoNotification → Intercept
    • Configuration: Apps = Blink Home Monitor (or whatever you want to capture)
  4. Add a Task with one HTTP Request action:
    • Method: POST
    • URL: http://YOUR_PC_IP:8787/shield/notifications
    • Headers: Content-Type: application/json
    • Body: 
      {
  "app":       "%anpkg",
  "title":     "%antitle",
  "text":      "%antext",
  "intentUri": "%anintent",
  "extras":    "%anextras",
  "ts":        %TIMES000
}
  5. Save the profile. Trigger a test notification (e.g. motion in front of a Blink cam, or any app you set up). Refresh this list below.

Why phone, not Shield? AutoNotification's Notification Listener service is reliable on phones; on Android TV it needs sideloading + ADB-granted listener permission and not all apps fire notifications to the TV's launcher. Phone is the simpler path.

Doesn't have to be Blink. Any app's notifications can be captured — fire them to Shield from one place.

        Notes on Blink notifications + auto-rotate
        
Blink's motion-detection notification on Android DOES carry a deep-link intent that opens the specific camera. The PC bridge can't directly grab that link — it's only on the Android TV Device. Workaround: install Tasker (or AutoApps + AutoNotification) on the Android TV Device, write a profile that captures the Blink notification's intent string, then POST it back to the bridge via HTTP. From there the bridge can replay it via adb shell am start -d <intent>.

        
Auto-rotate-on-Shield: the "Set Orientation" app (com.pittvandewitt.orientation) or "Rotation Control" can force landscape on apps that default to portrait. Add to the Quick Launch grid by editing SHIELD_APPS in this file once you know the exact package on your TV.
