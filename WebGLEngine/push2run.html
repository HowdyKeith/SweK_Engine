🔊 Push2Run

Push2Run watches your phone pushes / clipboard / hotkeys and runs a local command when text matches. These rules forward a verb to the running engine. Set the path to swek-cmd.bat once, then paste each rule into Push2Run as Run a program (Program = the bat, Parameters = the args below).

1 · Path to the helper

It's in your project root next to START_BUN_Full.bat. This only changes what the copy buttons paste.

2 · Setup in Push2Run

  1. Install Push2Run (push2run.com) and connect it to Pushbullet/Join (or use its hotkeys/clipboard).
  2. Add a Command: Words to match = your trigger phrase (e.g. "engine city"), Action = Run a program.
  3. Program = the bat path above. Parameters = the args from the table (copy button).
  4. The engine must be open + the bridge running on 8787. Speak/type your phrase → the engine reacts.
