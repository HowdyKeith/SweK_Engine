What this will not claim

Your own cats (optional)

No cat photographs ship with this engine. The reactions above are Unicode emoji, which belong to nobody. The project that inspired this one bundles photos of specific TikTok cats; those are somebody's copyrighted pictures, and this engine publishes public release zips, so vendoring them would redistribute them. Point this at a folder of your own images instead — a file per expression name (smile.png, shock.png, glare.png, angry.png, sad.png, kiss.png, puff.png, wink.png, neutral.png) and it will use those instead of the emoji.
