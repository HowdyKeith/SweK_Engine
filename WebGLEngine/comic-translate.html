📖 Comic Translator

A front door for ogkalu2/comic-translate — bubble detection, OCR, inpaint cleaning, and LLM translation of comics/manga in many languages and formats (Image, PDF, EPUB, CBR, CBZ). The engine detects, installs, and launches it; the OCR + translation run on this rig (and it can translate with an LLM you configure inside the app, Claude included).
