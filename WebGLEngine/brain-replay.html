Brain Replay

The brain records every decision it makes. This plays them back from the first one, as slowly as you like.

What this is, and what it is not

It replays what the brain CHOSE and whether it HIT. Every record carries a sequence number, a domain, the option picked, the selection mode, and the outcome. Played from seq 0 you can watch the hit rate climb out of noise — that is the brain learning, in the only terms it wrote down.

It does not replay the network changing, and it cannot. The weights are written to one file each and overwritten — only the latest snapshot survives, so there is no history to play. That is a real gap in the engine, not a limit of this page.
