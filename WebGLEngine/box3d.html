🧊 Box3D

Erin Catto's Box3D rigid-body engine, compiled to WebAssembly, built or shared across your fleet — and provably identical on every machine. That determinism is the hard part, and it's done.

✅ Proven across platforms

The canonical 600-tick scenario, run independently on two different CPU architectures, produced the same hash in real WASM mode. Same bytes in → same bits out.

What it is

The WASM is compiled once per box (with emsdk) or, on a machine that can't build, pulled from a fleet peer that already has it — the whole fleet ends up sharing one binary. A thin SweK shim exposes worlds, box and ship bodies, impulses and transforms, and a state hash for desync detection. It's the substrate under the kaiju city destruction, the fire lava, and the Endless Sky flight sandbox — the same physics, everywhere.

Why the determinism matters

  • Co-op lockstep — peers step the same inputs and stay bit-identical; esAuthority (HRW-hashed ownership) is already in place.
  • Fleet-scale training — run the same environment on Mac + Galaxina + PurtyGF as parallel, reproducible envs for the GPU Brain.
  • Trustworthy replays — a recorded input stream replays identically on any box.
