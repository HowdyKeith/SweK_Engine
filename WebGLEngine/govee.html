API key

Get a free key in the Govee Home app → Profile → Settings → Apply for API Key (it's emailed to you). It stays on this PC (server-side). Uses the Govee Developer/Cloud API.

Devices

Scan to list your Govee lights, then control them here.

Cloud API is rate-limited (~10k calls/day, brief per-device throttle), so changes may lag a beat. The engine can also drive all bulbs at once for alert flashes via /govee/all-color.
