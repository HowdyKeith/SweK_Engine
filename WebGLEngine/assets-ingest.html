Templates (name → folder)

Files matching a pattern are filed into that subfolder (first match wins, top to bottom). Anything that matches nothing stays in the root for you to triage in the Asset Library. * matches any run of characters.

PatternFolder

Game roles (library → spawns)

Which library folders feed each spawn system — a kaiju / dungeon monster / civ defender / terrain NPC can be drawn from these. Comma-separated folder names. The engine asks window.assetRoles.pick("kaiju") for a model.

RoleFoldersModels

Asset heights (spawn-scale normalisation)

Models are scaled at spawn so in-world height = target. Native sizes are measured by the engine on load — open the engine page once, then Export and send the JSON back to bake into the shipped seed. —

RoleTarget height (units)

Per-asset override — reuse one model at a different size (e.g. the marauder mech as a tiny insect or aquarium shrimp). Set a target for one asset; leave role as (any) for all roles, or pick a role to override just that use.
