Skillbook trial

A two-arm trial, run end to end: same questions, one arm with the hint and one without. Every number below comes back from skillTrial and skillbook — this page computes none of them.

The proposer is a deterministic mock, not a model. The trial, the device, the critic and the verdict are real; what is proposed is generated from the seed at the malformed rate you set. So this tests the harness — that a real effect comes back PROVEN, a null comes back RETIRED and a thin sample comes back UNDERPOWERED. Whether a hint helps a real model needs a real model.
The proposer is the local model named below, reached through the engine's own llmHost setting — the same base ragBridge and the GPU-brain bridge use, so pointing the fleet at another machine moves this too. The trial, the device, the critic and the verdict are unchanged; the only difference is who answers. Nothing here tells the model how often to be wrong, so there is no "told" column — the numbers on the right are the only numbers there are.

What the states mean

statemeaning
PROVENthe drop cleared the size bar and its own standard error. Only these are ever injected into a prompt.
UNDERPOWEREDa real drop the sample cannot separate from noise. Not retired — retiring it would discard something that may be true. Never injected.
RETIREDmeasured and did nothing. Kept with its numbers, because "we tried this and it did nothing" is a result nobody should rediscover.
PROPOSEDnot trialled, or trialled on too few runs to count. Never injected.
