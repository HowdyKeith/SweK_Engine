Instruments

Every graded instrument in the lab, and what each one is measured against. The rule here is that an instrument is only real if it can be graded against truth we own — analytic or self-generated. A plausible-looking readout with no checkable answer is decoration, so every card names its key.

What the gates measured

A gate's verdict is a word; its ARGUMENT is a table of numbers, and 67 of this tree's gates print one that has never survived the terminal it was written to. The tables below are those numbers, read from the gate's own report rather than retyped — the discipline this tree takes from 3Blue1Brown's manim, which is not animation but that the explanation is generated from the same objects as the argument, so it cannot drift from it. Emitting is off by default: run a gate with SWEK_GATE_REPORT=1 and its table appears here.
