🦊 Camoufox

install & detect · runs on the PC bridge —

Camoufox is the anti-detect Firefox we drive with Playwright — the modern replacement for the retired IE WebBrowser control. It installs into a dedicated venv (C:\camoufox_env) so it never touches the ComfyUI environment. The browser binary is a separate ~300–400 MB download.

Install steps (idempotent — safe to re-run)

1
Create venv
python -m venv — skipped if it already exists
2
Install camoufox
pip install -U camoufox (in the venv)
3
Fetch browser
python -m camoufox fetch — the big 300–400 MB download
