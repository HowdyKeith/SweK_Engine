Two things make this fast enough to watch, and both come from Michael Fogleman’s primitive by way of ondras/primitive.js (MIT). The colour is never searched for. Compositing a colour c at alpha a gives new = cur(1-a) + c*a, so the squared error is a quadratic in c with exactly one minimum — c = (target - cur)/a + cur, averaged over the shape’s pixels. That is the exact least-squares answer, not a heuristic. And each candidate is scored only where it lands, because a shape changes nothing outside itself. The gate checks both: it grid-searches all 256 values of a channel and finds none that beats the closed form, and it computes the score both ways and asserts they agree to the bit.
