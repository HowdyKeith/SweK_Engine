The one thing you asked for that a browser will not tell you

VRAM is not exposed to a page, by any browser. WebGPU withholds device memory deliberately — it is a fingerprinting surface — so there is no API that returns it. What exists is adapter.limits.maxBufferSize (the largest single allocation the driver will grant) and, on newer Chrome, adapter.info naming the vendor and device. Those are proxies, and they are labelled as proxies below. A page that printed a confident "6 GB VRAM" from a guess would be worse than one that says the browser will not say, because somebody would plan against it.

What CAN be decided for free: whether there is a WebGPU adapter at all, whether the disk quota is even large enough to cache the model, whether shader-f16 is available, and whether a download already happened.

What this box reports

Per model — and why "maybe" is the best honest answer

Sizes are gemma-gem's own README numbers, kept as data with the source named so a reader can check them. Three outcomes, not two: no means a measured fact rules it out, unknown means something needed could not be read, and maybe means nothing measurable rules it out. Never "yes" — the one number that would decide it is the one nobody can read.
