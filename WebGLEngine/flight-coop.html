👥 Co-op Lockstep

Two peers each own a fleet, step the same shared world from each other's inputs, and compare a per-tick stateHash. If the hashes ever disagree, that's a desync — caught instantly. This page runs both peers in one tab over a loopback link (with adjustable latency) so you can watch it stay locked; on the fleet the identical session/net code runs across real boxes.

Both panels are the same simulation advanced independently by two peers — if lockstep holds they are pixel-for-pixel identical and the two hashes match every tick.
