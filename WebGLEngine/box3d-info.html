🧱 Box3D — the rigid-body destruction layer under the kaiju

What this is

erincatto/box3d (alpha, MIT) — Erin Catto's 3D successor to Box2D — compiled to WASM and used as a specialized rigid-body layer over the kaiju world, not a replacement for it. box3d owns the destruction: buildings topple, debris tumbles, thrown props spin. The kaiju keeps its own systems for everything else — GPU flow-field locomotion, ClothSim capes, water, civ AI.

Standing buildings are static boxes the existing renderer draws as before; toppling wakes a building to a dynamic body so box3d takes over its fall. The kaiju is a kinematic collider the flow-field AI drives each frame — it shoves whatever it sweeps through. A thin C shim (physics/box3d/box3d_shim.c) exposes a flat API bound by physics/box3d/box3dLoader.js; physics/kaijuBox3d.js is the bridge and physics/kaijuBox3dScene.js the city scene.

Fleet-share

  
physics/box3dNet.js shares the destruction the same two ways the NPCs are shared:

  

    
owner-authoritativeone peer owns the city, steps it, broadcasts kaijuBox3d.pack() each tick; the others applyRemote(packet) and draw remoteBodies(). No determinism needed — the owner is truth.

    
lockstepevery peer registers the same ships in canonical order and steps the same shared WASM world from the same inputs, gating each tick until all peers' {turn,thrust} are in, then compares stateHash. This is the cross-peer path -- my ship rams your ship and both machines agree. The deterministic core is physics/box3dLockstep.js (createLockstepSession) and the net transport is physics/box3dLockstepNet.js (createLockstepNet -- send-ahead input delay + per-tick hash exchange); the room bus carries it. Safe because box3d is WASM (spec-defined IEEE-754), unlike the GPU brain, whose floats can never match.

  

  
Run selfTest() on two machines: equal stateHash after 600 ticks proves cross-platform determinism — the precondition for input-only lockstep.






  
Cross-machine sync (the lockstep precondition)

  
Run the canonical box3d scenario here, then on the other machine. Equal final hash means the
     Mac and PC boots evolve bit-for-bit the same — cross-peer lockstep is safe. A different hash means the
     WASM diverges across platforms and you stay on owner-authoritative. Uses the real WASM when built (that is
     what has to match); the JS fallback otherwise.

  

    
    
    
    
  

  

  






  
Proved without a GPU

  

    
kaiju-box3d-selfcheckthe bridge: register / step / sync / static-skip, plus the interaction verbs (impulse, throw+spin, kinematic drive, wall→debris). 19 checks.

    
kaiju-box3d-scene-selfcheckthe city scene: buildings register standing, kaiju drives, topple falls + shoves, debris scatters, props fly, determinism. 13 checks.

    
box3d-net-selfcheckfleet-share: pack/apply round-trips over JSON, kinds survive the wire, stable ids, lockstep catches a desync. 11 checks.

    
box3d-lockstep-selfcheckcross-peer lockstep: two peers on the same input stream stay bit-identical for 120 ticks, the input gate holds a tick until all peers report, and a divergent input is caught as a desync. 6 checks.

    
box3d-lockstep-net-selfchecklockstep over a laggy mock network: two peers exchange inputs with send-ahead delay and stay within a couple ticks + bit-identical hashes every tick, input lead stays bounded, a real same-inputs/different-result divergence is caught by the hash exchange, and it survives higher latency. 7 checks.

    
box3d-smokethe real WASM through the bridge: a pile settles, a thrown crate travels + tumbles, a kinematic sweep topples a tower, two runs hash identically. Rig-gated (needs the built WASM).
