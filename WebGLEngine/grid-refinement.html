What adaptivity costs

A grid that refines where the action is sounds free. It is not, and the price is measurable because the right answer is exactly zero: in the continuum a refinement interface does not exist — same ε, same μ, same c on both sides. A change of cell size is a change in how the problem is written down, not in the problem. Every photon that comes back is pure numerical artefact, and its size is the price.

1. Send a pulse through an interface

The reference is a uniform grid at the coarse spacing with the same shared time step — the grid you would have had if you had not refined — so the number is the price of the refinement, not of the resolution. At ratio 1 it reads exactly zero, which is the control saying the machinery itself adds nothing.

2. The two costs

The reflection is second order in cell size and it saturates in ratio. Going from 2× to 6× costs about a third more, not three times more — the interface cost approaches a ceiling set by the coarse side alone. And second order means the interface introduces more of the error that was already there, not a new one. That is a better answer than "it's fine" or "it's broken".
The cost that isn't a measurement is the larger one. One time step is shared, so Sfine = ratio × Scoarse and the finest cell limits the whole domain. The magic time step therefore exists on at most one side of any refinement interface — and fdtd-selfcheck already measured that shrinking the step makes 1D FDTD worse. Refining any part of a grid takes the one exact configuration away from every other part. The reflection is second order and bounded; that is neither.
