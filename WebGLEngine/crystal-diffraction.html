◆ Crystal diffraction — the front door

Two graded modules that had only a generic door — an instruments row rendered as text by instrument-bench.html — and could not have had a page of their own: a static node:url import at the top of each file made them fail to load in a browser entirely. The bench never noticed and could not have, because it runs the reporting half in node. The import now sits inside the CLI guard that wanted it. This page computes nothing. Every figure below is a return value from a module under physics/crystal/ with its own gate, or from one of the two roundhouse binds built here twice — honest and planted. Each panel's grey line is the key that module is graded on, and here the keys are exact zeros arriving by three unrelated mechanisms: interference, arithmetic, and conjugation.
