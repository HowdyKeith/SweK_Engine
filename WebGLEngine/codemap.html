Codemap

Every file in this engine, as a building. Height is lines. Colour is the last version that mentioned it.

What this is, and what it is not

cosmtrek/mindwalk replays a coding-agent session on a 3D map of a codebase — it reads the agent's own transcripts and colours each file by how deeply one run touched it. This is not that. This engine is built through a chat window that writes no session files, so replaying a session is not something this box can honestly do, and a visualisation of nothing would be worse than no visualisation.

What it maps instead is what this tree already carries: a vNNNN marker in the comments, kept for 2500 versions. That is a real per-file record of when each file was last thought about, mined from a convention that was never meant as telemetry. Not one session — every session, flattened.

The honest limits of this measurement

A marker is a floor, not a timestamp. A file that mentions v2100 in a comment about history reads as v2100 even if it was edited this morning without a new marker. It says "this file was thought about at least this recently", nothing stronger.

Unmarked is unknown, not old. Half this tree carries no marker at all — some is third-party, some predates the convention, some was simply never commented. They are grey, not dark red. Guessing an age for them would be exactly the failure this engine's changelog is a record of.
